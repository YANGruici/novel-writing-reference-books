## 一、黄金三章 · 核心方法论

### 1. 前三章只交代三件事（不是世界起源）
| 顺序 | 内容 | 比喻 |
|---|---|---|
| ① 引擎 | 主角此刻最迫切的欲望/困境（求生、复仇、脱贫） | 汽车引擎 |
| ② 钩子 | 世界与现实的第一个差异点/颠覆点——**必须通过行动呈现** | 钩子 |
| ③ 承诺 | 一个立即的、微小的、可见的后果或希望（哪怕是被追杀） | 契约 |

**关键认知**："黄金三章"的本质不是三章，而是**读者按下"加入书架"前的耐心时长**。

**世界观铺垫技巧**："将世界观打碎成玻璃碴，撒在主角奔跑的血迹里"——读者跟着主角的伤口触碰到世界的棱角，而不是读设定说明书。

### 2. 代入感三法（感官优先，逻辑靠后）
1. **身体感受切入**：开篇第一段写强烈的生理感受（剧痛/寒冷/饥饿/窒息），读者先于理性在生理上与主角同步。
2. **动作替代心理**："他很悲伤"无效 → "他抓起凉馒头啃两口，发现牙关一直咬着"。
3. **信息只给后果，不给前传**：不解释"灵气复苏十年后"，直接写"安检门第三次闪红，安检员瞥了眼菜刀：'先生，持C级法器证走左侧通道。'"

### 3. 反套路开篇三法（认知杠杆）
1. **完美人设崩塌法**：龙傲天开篇三百字暴露核心脆弱（无敌仙尊颤抖着擦鞋上的泥点——那是上辈子心魔的印记）。
2. **时间错位悬念法**：从事件中段/结果切入（"判决书下来那天，我终于想起自己是穿越者，可惜晚了，流放飞船明早出发"）。
3. **日常突触法**：平凡场景中插入无法解释的细微异样（实习生咖啡杯里糖块溶解速度永远慢十七秒）。

### 4. 自检法（停顿点）
写完开篇三章，把每段情节推进和情绪变化用一句话概括列成清单。问：读者公交上刷手机，看到哪句会停下往上翻？**连续五句没有"停顿点"= 节奏出问题**。

## 二、节奏控制 · 核心方法论

### 1. 快慢交替（间歇跑，不是短跑）
- **快**（短句/短段/快速推进）：打斗、冲突、对话交锋——"他拔剑。寒光一闪。血溅三尺。"
- **慢**（长句/细腻/铺陈）：环境、心理、细节、情感升温。
- **黄金比例 3:1**：三章紧张剧情后给一章"喘息"，为下一波高潮蓄力。

### 2. 章节钩子四型
| 类型 | 示例 |
|---|---|
| 悬念型 | 他口袋里的照片，为什么和她有关？ |
| 期待型 | 下一章，她终于要说出真相了。 |
| 冲突型 | 门被推开，进来的竟是他最不想见的人。 |
| 反转型 | 原来这一切都是计划好的——但被谁？ |

### 3. 黄金三章节奏表（编辑只看前三章）
| 章 | 字数 | 任务 |
|---|---|---|
| 第一章 | 500字内主角登场；2000字内完成首秀展示性格 | 结尾埋悬念/危机 |
| 第二章 | 获得转机（系统/觉醒/贵人）；初步展示金手指 | 结尾立第一个小目标 |
| 第三章 | 首次冲突交锋；展示成长空间 | 结尾更大的危机/机遇 |

**三位一体**：立人设 + 展矛盾 + 留悬念。

### 4. 高潮节奏
- 每 10 章至少一个小高潮；每 30 章一个大转折；每章至少一个"爽点"。
- 压抑与释放：甜前先虐、虐前先甜；公式 **爽点×3 + 虐点×1 + 快速解决**；虐点不超过 2 章。

### 5. 常见节奏病与解法
| 病 | 表现 | 解 |
|---|---|---|
| 流水账 | 时间线驱动（起床→上班→下班） | 用冲突驱动（迟到→地铁遇怪老人→被骂→老人递名片） |
| 中期疲劳 | 30万字后情节重复 | 换地图/加新角色/升级体系/制造危机 |
| 战力崩坏 | 三章满级 | 提前规划战力体系；十章升三级尚可，三章满级必死 |

### 6. 章节自查清单
这一章爽点是什么？章末有没有钩子？快慢是否交替？有没有超 200 字纯环境描写？心理活动是否超 500 字？对话是否推动剧情？

## 三、流量底层逻辑（算法赛马时代）

### 1. 门面流量（3 秒定生死）
- **书名公式**：赛道热词 + 身份反差 + 核心爽点（《通灵小奶团：全村老祖都听我劝》）；杜绝《浮生录》式空泛。
- **三段式简介**：①主角困境/共情痛点 → ②金手指/爽点预期 → ③长线悬念。三行讲透最大看点。
- **标签**：3-5 个精准细分标签，不蹭泛标签。

### 2. 内容流量（三大核心指标：完读/追读/收藏）
- 黄金三章硬规则：**500 字内抛核心冲突**；第一章绝境 → 第二章金手指 → 第三章小逆袭（困境-机遇-爽点闭环）。
- 短期钩子放每章结尾；长线伏笔贯穿全书。
- 每两章一个小爽点，每十章一个大高潮。

### 3. 连载流量
- 稳定更新：日更 4000（兼职）/6000（全职），储备 3-7 天存稿；断更三天流量断崖。
- 一本书至少连载至 30 万字走完首秀周期再评判。
- 8-10 万字开书测，多套封面书名测试择优。

### 4. 情绪裂变
- 共情痛点（原生家庭/职场压抑/生活窘迫）+ 先抑后扬。
- 正向治愈（温暖向善内核）拓宽圈层。
- 预埋话题点引导评论互动，互动数据触发追加推荐。

## 五、经典叙事结构补充（GitHub 写作社区资源）

### Dan Harmon 故事圈（8 步循环，影视/小说通用）
```
① 主角在舒适区 → ② 想要某物 → ③ 进入陌生情境 → ④ 适应
→ ⑤ 得到所求 → ⑥ 付出代价 → ⑦ 回到熟悉情境 → ⑧ 改变（比出发时更强大/更不同）
```
> 用途：卷级/全书级结构设计；每卷可视为一个"故事圈"，长篇 = 多个嵌套故事圈。
> 与爽点结合：⑥ 付出代价要短（≤2章），⑦⑧ 是情绪释放点。
